# BUG-001 — Кнопка «Начать бесплатно» в блоке «Начните решать задачи» не перенаправляет пользователя в раздел «Задачи»

**Серьёзность:** Minor

## Шаги воспроизведения

1. Открыть [главную страницу](https://eduson-qa.itresume.ru/).
2. Пролистать страницу до блока «Начните решать задачи».
3. Нажать кнопку «Начать бесплатно».

## Ожидаемый результат

После нажатия кнопки «Начать бесплатно» пользователь перенаправлен в раздел «Задачи».

## Фактический результат

После нажатия кнопки пользователь остаётся на главной странице. Адрес страницы изменяется на:

```text
https://eduson-qa.itresume.ru/#
```

## Дополнительная информация

В DOM у элемента указано значение `href="/#"`, которое ведёт на текущую страницу.

## Окружение

- **Браузер:** Google Chrome 153.0.8010.54
- **ОС:** Windows 11, 64-bit
- **URL:** [https://eduson-qa.itresume.ru/](https://eduson-qa.itresume.ru/)
