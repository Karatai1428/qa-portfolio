# BUG-003 — Поле поиска в разделе «Задачи» не позволяет ввести более 10 символов

**Серьёзность:** Minor

## Шаги воспроизведения

1. Открыть раздел [«Задачи»](https://eduson-qa.itresume.ru/problems).
2. Установить курсор в поле «Поиск».
3. Ввести поисковый запрос `структура задачи`.

## Ожидаемый результат

Поле позволяет полностью ввести поисковый запрос `структура задачи` длиной более 10 символов.

## Фактический результат

После ввода первых 10 символов поле перестаёт принимать новые символы. Вместо запроса `структура задачи` в поле отображается `структура `.

## Дополнительная информация

В DOM у поля поиска указан атрибут `maxlength="10"`:

```html
<input id="search" type="text" name="search" maxlength="10" class="field__input">
```

- **Браузер:** Google Chrome 153.0.8010.54
