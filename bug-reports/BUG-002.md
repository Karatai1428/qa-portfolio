# BUG-002 —  После авторизации вместо логина пользователя в правом верхнем углу отображается статичный текст `username`

**Серьёзность:** Minor

## Шаги воспроизведения

1. Открыть [страницу авторизации](https://eduson-qa.itresume.ru/account/login).
2. Ввести тестовые учётные данные:
   - логин — `tester01`;
   - пароль — `Qwerty123`.
3. Выполнить авторизацию.

## Ожидаемый результат

После успешной авторизации в правом верхнем углу отображается логин текущего пользователя, например `tester01`.

## Фактический результат

После успешной авторизации в правом верхнем углу отображается статичный текст `username` вместо логина текущего пользователя `tester01`.

## Дополнительная информация

В DOM отображается статическое текстовое значение `username`:

```html
<a role="menuitem" aria-haspopup="true" href="/account" class="header__user" aria-expanded="false">
  <span>username</span>
</a>
```
