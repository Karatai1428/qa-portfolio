# Краткий отчёт о тестировании

## Общая информация

**Проект:** тестирование учебного веб-приложения  
**Тестируемое приложение:** [https://eduson-qa.itresume.ru/](https://eduson-qa.itresume.ru/)  
**Тип проекта:** учебный  
**Вид тестирования:** ручное функциональное и UI-тестирование

## Цель тестирования

Проверить основные пользовательские сценарии веб-приложения, выявить дефекты и подготовить примеры тестовой документации для демонстрации практических навыков ручного тестирования.

## Проверенные области

В рамках проекта были рассмотрены:

- главная страница;
- форма регистрации;
- форма авторизации;
- навигация по веб-приложению;
- раздел «Задачи»;
- поиск задач;
- основные элементы пользовательского интерфейса.

## Выполненная работа

В ходе учебного проекта:

1. Проведено функциональное и UI-тестирование основных разделов веб-приложения.
2. Проверены позитивные и негативные пользовательские сценарии.
3. Составлены тест-кейсы для формы регистрации.
4. Подготовлен чек-лист проверки формы авторизации.
5. Обнаруженные дефекты оформлены в виде баг-репортов с указанием шагов воспроизведения, ожидаемого и фактического результатов, серьёзности и окружения.
6. Для дополнительного изучения отдельных дефектов использовались Chrome DevTools.
7. Подготовлен краткий отчёт о результатах тестирования.

## Использованные инструменты

- Google Chrome;
- Chrome DevTools;
- GitHub;
- Markdown.

## Тестовая документация

В рамках проекта были подготовлены:

- тест-кейсы формы регистрации;
- чек-лист формы авторизации;
- баг-репорты по различным разделам приложения;
- краткий отчёт о тестировании.

Опубликованные документы представляют собой выборку материалов, подготовленную для демонстрации навыков составления тестовой документации. Они не отражают полный объём выполненного тестирования.

## Результаты

В ходе тестирования было обнаружено и оформлено **17 дефектов**.

В репозитории опубликованы **3 выбранных баг-репорта**, демонстрирующих структуру и качество оформления дефектов. Остальные обнаруженные дефекты в демонстрационную документацию не включены.

Представленные дефекты связаны со следующими областями:

- навигация с главной страницы;
- отображение данных авторизованного пользователя;
- работа поиска в разделе «Задачи».

## Окружение

- **Операционная система:** Windows 11, 64-bit;
- **Браузер:** Google Chrome 153.0.8010.54.

## Ограничения

Проект выполнялся в учебных целях. Формальные требования были предоставлены только для полей регистрации и авторизации.

Опубликованные тест-кейсы и чек-лист предназначены для демонстрации навыков проектирования проверок и не являются результатами полного тестового прогона. Поэтому в документах не приводятся статусы выполнения, фактические результаты и статистика прохождения проверок.

В тестовой документации использованы только вымышленные учётные данные, не содержащие персональной информации.

## Итог

В рамках учебного проекта были проверены основные пользовательские сценарии веб-приложения, подготовлены тест-кейсы и чек-лист, а также обнаружено и оформлено 17 дефектов.

Проект позволил применить на практике навыки ручного функционального и UI-тестирования, составления тестовой документации, оформления баг-репортов и анализа элементов веб-приложения с помощью Chrome DevTools.
