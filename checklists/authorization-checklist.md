# Чек-лист формы авторизации

## О документе

В документе представлен чек-лист проверки формы авторизации, подготовленный в рамках учебного проекта.

Чек-лист содержит позитивные и негативные проверки основной функциональности формы, валидации полей, навигации и пользовательской сессии.

Документ предназначен для демонстрации навыков составления тестовой документации. Статусы и результаты выполнения проверок не указаны.

**Страница авторизации:**  
[https://eduson-qa.itresume.ru/account/login](https://eduson-qa.itresume.ru/account/login)

## Позитивные проверки

| ID | Проверка |
|---|---|
| CL-AUTH-001 | Авторизация с валидными логином и паролем |
| CL-AUTH-002 | Авторизация с валидными email и паролем |
| CL-AUTH-003 | Авторизация с логином минимально допустимой длины — 4 символа |
| CL-AUTH-004 | Авторизация с логином максимально допустимой длины — 16 символов |
| CL-AUTH-005 | Авторизация с паролем минимально допустимой длины — 6 символов |
| CL-AUTH-006 | Авторизация с паролем максимально допустимой длины — 16 символов |
| CL-AUTH-007 | Отображение и скрытие пароля с помощью соответствующей иконки |
| CL-AUTH-008 | Отправка заполненной формы нажатием клавиши Enter в поле «Пароль» |
| CL-AUTH-009 | Переход на страницу регистрации по ссылке «Регистрация» |
| CL-AUTH-010 | Переход на страницу восстановления пароля по ссылке «Забыли пароль?» |
| CL-AUTH-011 | Перенаправление пользователя на главную страницу после успешной авторизации |
| CL-AUTH-012 | Сохранение авторизации после обновления страницы |

## Негативные проверки

| ID | Проверка |
|---|---|
| CL-AUTH-013 | Авторизация с незарегистрированным логином |
| CL-AUTH-014 | Авторизация с незарегистрированным email |
| CL-AUTH-015 | Авторизация с валидным логином и неверным паролем |
| CL-AUTH-016 | Отправка формы с незаполненными полями «Логин или почта» и «Пароль» |
| CL-AUTH-017 | Отправка формы с незаполненным полем «Логин или почта» |

| CL-AUTH-019 | Авторизация с email некорректного формата, например `test@domain` |
| CL-AUTH-020 | Авторизация с паролем в неверном регистре: `qwerty123` вместо `Qwerty123` |
| CL-AUTH-021 | Авторизация с пробелами в начале и конце логина |
