# QA Portfolio

## О проекте

В репозитории представлены материалы, подготовленные в рамках учебного проекта по тестированию веб-приложения.

## Содержание

- Чек-листы
- Тест-кейсы
- Баг-репорты
- Итоговый отчёт

## Выполненные виды тестирования

- функциональное тестирование;
- тестирование пользовательского интерфейса;
- проверка валидации полей;
- позитивное и негативное тестирование.

## Инструменты

- Google Chrome;
- Chrome DevTools;
- GitHub;
- Markdown.

> Все материалы проекта подготовлены в учебных целях.
