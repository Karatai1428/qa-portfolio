# QA Portfolio — тестирование веб-приложения

## О проекте

В репозитории представлена выборочная тестовая документация, подготовленная в рамках учебного проекта по тестированию веб-приложения.

**Тестируемое приложение:**  
[eduson-qa.itresume.ru](https://eduson-qa.itresume.ru/)

**Цель проекта:**  
Провести функциональное тестирование основных пользовательских сценариев веб-приложения, подготовить тестовую документацию и описать обнаруженные дефекты.

## Представленные материалы

- тест-кейсы формы регистрации;
- чек-лист проверки авторизации;
- отдельные баг-репорты по различным разделам приложения;
- краткий отчёт о тестировании.

## Рассмотренные области

- регистрация пользователя;
- авторизация пользователя;
- навигация по приложению;
- работа элементов главной страницы;
- поиск в разделе «Задачи».

## Применённые техники и виды тестирования

- позитивное и негативное тестирование;
- анализ граничных значений;
- классы эквивалентности;
- проверка обязательных полей;
- функциональное тестирование пользовательских сценариев.

## Инструменты

- Google Chrome;
- Chrome DevTools;
- GitHub;
- Markdown.

## О документации

Материалы отобраны для демонстрации навыков составления тестовой документации и не представляют полный тестовый прогон приложения.

Тест-кейсы разработаны на основании требований к форме регистрации. Согласно требованиям, длина логина должна составлять от 4 до 16 символов, а длина пароля — от 6 до 16 символов.

Использованные в тест-кейсах учётные данные являются вымышленными и не содержат персональной информации. Статусы выполнения и фактические результаты не указаны, поскольку тест-кейсы представлены как примеры проектирования проверок.

Чек-лист содержит перечень спроектированных проверок формы авторизации без результатов выполнения и статусов.

Баг-репорты представлены как отдельные примеры оформления обнаруженных дефектов и не связаны с опубликованными тест-кейсами. В них указана предварительная оценка серьёзности дефектов. Приоритеты не приводятся, поскольку они определяются командой с учётом бизнес-требований.
