# Тест-кейсы формы регистрации

## О документе

В документе представлены тест-кейсы формы регистрации, разработанные на основании требований учебного проекта.

Согласно требованиям:

- длина логина — от 4 до 16 символов;
- длина пароля — от 6 до 16 символов;
- все поля формы являются обязательными.

Тестовые данные являются вымышленными и не содержат персональной информации. Тест-кейсы подготовлены для демонстрации навыков проектирования тестовой документации и не содержат результатов фактического тестового прогона.

## Позитивные тест-кейсы

### REG-001 — Успешная регистрация с валидными данными

**Приоритет:** High

**Предусловия:**

- открыта [страница регистрации](https://eduson-qa.itresume.ru/account/creation);
- пользователь не авторизован;
- email `tester01@example.com` не зарегистрирован в системе.

**Тестовые данные:**

| Поле | Значение |
|---|---|
| Логин | `tester01` |
| Электронная почта | `tester01@example.com` |
| Пароль | `Qwerty123` |

**Шаги:**

1. Ввести в поле «Логин» значение `tester01`.
2. Ввести в поле «Электронная почта» значение `tester01@example.com`.
3. Ввести в поле «Пароль» значение `Qwerty123`.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**

- пользователь перенаправлен на [главную страницу](https://eduson-qa.itresume.ru/);
- в правом верхнем углу отображается имя пользователя `tester01`;
- на адрес `tester01@example.com` отправлено письмо с подтверждением.
